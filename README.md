# 🎯 PewPew Aim FX

> **Admit Hackathon 2026 · Motion — «Камера вместо джойстика» · A / GAME**

**PewPew Aim FX** — браузерный бесконтактный шутер, в котором обычная веб-камера становится игровым контроллером.

Игрок управляет прицелом, стрельбой и способностями с помощью движений рук и лица — без мыши, клавиатуры и внешних датчиков.

---

## 🎮 Что нужно сделать игроку

Откройте игру в браузере, разрешите доступ к камере и встаньте перед ней.

| Жест              | Действие                                               |
| ----------------- | ------------------------------------------------------ |
| 👉 **Pointing**   | Указательный палец управляет лазерным прицелом         |
| 😮 **Open Mouth** | Открытие рта запускает лазерный выстрел                |
| ✋ **Open Palm**  | Раскрытая ладонь активирует силовой щит                |
| ✊ **Power Fist** | Удержание сжатого кулака заряжает и запускает EMP-удар |

### Игровой цикл

```text
Движение игрока
       ↓
Распознавание камерой
       ↓
Определение жеста
       ↓
Игровое действие
       ↓
Попадание / способность / очки
       ↓
Следующий игровой момент
```

Раунд ограничен по времени. В процессе появляются разные типы целей и вражеские снаряды, от которых игрок должен защищаться.

# ⚠️ Режим «Ошибка»

Режим «Ошибка» — обязательный твист кейса Motion.

Система не ограничивается сообщением вроде **«жест не распознан»**. Она анализирует положение ключевых точек руки и лица и пытается определить конкретную причину неправильного движения.

После обнаружения ошибки игрок получает инструкцию, **что именно изменить**.

### Реализованные типы ошибок

| Ошибка                         | Что анализируется                         | Подсказка                                                           |
| ------------------------------ | ----------------------------------------- | ------------------------------------------------------------------- |
| ☝️ Согнутый указательный палец | Угол между `MCP-PIP-TIP`                  | «Выпрями палец жестче — лазерный прицел сбивается при изгибе»       |
| 😮 Слабое открытие рта         | Амплитуда открытия рта                    | «Открой рот увереннее — сейчас амплитуда слишком мала для выстрела» |
| ✋ Неполная ладонь             | Количество раскрытых пальцев              | «Раскрой все 5 пальцев шире и поверни ладонь к камере»              |
| 📷 Рука у края кадра           | Положение кисти относительно границ кадра | «Смести руку ближе к центру для стабильного трекинга»               |
| 🌀 Слишком резкое движение     | Скорость перемещения прицела              | «Двигай рукой плавнее для стабильного прицеливания»                 |

### Принцип работы

```text
Landmarks
    ↓
Геометрические признаки
    ↓
Проверка условий
    ↓
Определение ошибки
    ↓
Конкретная подсказка
    ↓
Исправление движения
```

Таким образом, система объясняет не только **что произошло**, но и **как исправить движение**.

# 🧠 Техническая реализация

## Computer Vision

Для распознавания движений используются модели MediaPipe, работающие непосредственно в браузере.

Основной pipeline:

```text
Webcam
  ↓
getUserMedia()
  ↓
MediaPipe Hands
  +
MediaPipe FaceLandmarker
  ↓
GestureDetector
  ↓
Gesture / Error
  ↓
GameCanvas
```

### Hand tracking

MediaPipe Hands предоставляет 21 landmark для кисти.

На их основе собственная логика проекта определяет:

- состояние пальцев;
- углы между суставами;
- расстояния между ключевыми точками;
- положение кисти в кадре;
- скорость движения;
- состояние раскрытия ладони.

### Face tracking

FaceLandmarker используется для определения открытия рта.

Обработка лица выполняется с ограниченной частотой, чтобы уменьшить нагрузку на устройство.

---

# 🔧 Собственная логика распознавания

MediaPipe используется для получения landmark'ов. Решение о том, какой жест выполняет игрок, принимает собственная логика проекта.

В `GestureDetector` используются:

- векторная геометрия;
- углы между landmark'ами;
- евклидовы расстояния;
- скалярные признаки;
- пороговые значения;
- анализ движения во времени;
- frame counters и state machine для динамических действий.

Например, Power Fist определяется не только по одному кадру: система отслеживает состояние кулака во времени и использует его для зарядки EMP.

Это позволяет реализовать игровую логику поверх готовой модели компьютерного зрения без обучения собственной нейросети.

# ⚙️ Архитектура

Основные части приложения разделены по ответственности:

```text
WebcamView
    │
    ├── Camera input
    ├── MediaPipe processing
    └── Frame processing
            │
            ▼
     GestureDetector
            │
            ├── Gestures
            └── Error detection
                    │
                    ▼
              GameCanvas
                    │
                    ├── Targets
                    ├── Projectiles
                    ├── Player
                    ├── Shield
                    ├── EMP
                    └── Score / HUD
```

Игровой Canvas работает независимо от частоты инференса компьютерного зрения. Для движения прицела используется интерполяция, уменьшающая визуальный jitter.

---

# 🛡️ Отказоустойчивость

В проекте предусмотрены несколько механизмов обработки проблем с камерой и трекингом:

- проверка запуска трекинга через watchdog;
- GPU delegate для FaceLandmarker с fallback на CPU;
- сниженная сложность обработки для мобильных устройств;
- обработка отсутствия камеры;
- fallback-режим управления мышью для случаев, когда камера недоступна.

# 🕹️ Игровые элементы

Во время раунда игрок сталкивается с несколькими типами целей:

- **STANDARD** — обычная цель;
- **FAST** — быстрая цель;
- **SHOOTER** — цель, атакующая игрока;
- **GOLDEN** — специальная цель;
- **BOMB** — опасная цель.

Игровая система учитывает:

- счёт;
- комбо;
- точность;
- здоровье;
- уничтоженные цели;
- заблокированные снаряды;
- использование способностей;
- завершение раунда.

# 🚀 Запуск проекта

## Требования

- Node.js
- современный браузер с поддержкой WebRTC/WebAssembly;
- веб-камера для управления жестами.

## Установка

```bash
git clone https://github.com/aibarryss/pewpew_aim.git
cd pewpew_aim
npm install
```

## Запуск

```bash
npm run dev
```

После запуска откройте адрес, который выведет Vite в терминале, и разрешите браузеру доступ к веб-камере.

# 📌 Ограничения

Качество распознавания зависит от:

- освещения;
- положения игрока относительно камеры;
- видимости кисти и лица;
- качества веб-камеры;
- производительности устройства.

Для стабильного трекинга рекомендуется находиться перед камерой так, чтобы кисть полностью попадала в кадр.
