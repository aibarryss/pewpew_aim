# 🎯 PewPew Aim FX — Бесконтактный AI-шутер на жестах

> **Проект для Admit Hackathon** · Направление **A / GAME** (Кейс «Motion: Камера вместо джойстика»)

Веб-игра, в которой веб-камера становится контроллером. Игрок управляет лазерным прицелом и выстрелами исключительно движениями рук и пальцев прямо в браузере без мыши, клавиатуры или внешних датчиков.

---

## 🕹️ 1. Механика и жесты управления (4 жеста)

| Жест | Визуализация | Действие в игре |
|---|---|---|
| **👉 Pointing (Указательный палец)** | Кончик пальца перемещает лазерный прицел | Наведение и траектория прицеливания |
| **😮 Open Mouth (Открытие рта)** | Открытие рта на ~0.1 сек | Мгновенный лазерный выстрел в точку прицела |
| **✋ Open Palm (Раскрытая ладонь)** | 5 пальцев раскрыты в направлении камеры | Активация силового щита (отражает пули дронов) |
| **⚡ Power Fist (Сжатый кулак)** | Кулак удерживается 0.8 сек | EMP-удар (очистка экрана от вражеских целей) |

## ⚡ 2. Обязательный твист: Режим «Ошибка» (+20 баллов)

Система не просто фиксирует потерю трекинга, а в реальном времени анализирует биомеханику и геометрию кисти и лица (углы между фалангами пальцев, вектор ладони, амплитуду рта и плавность движений):

1. **Изгиб указательного пальца:**
   * *Срабатывание:* Угол между суставами `MCP-PIP-TIP` < 142°.
   * *Подсказка:* `«Выпрями палец жестче — лазерный прицел сбивается при изгибе»`.
2. **Слабое открытие рта:**
   * *Срабатывание:* Амплитуда открытия рта в диапазоне 0.08–0.14 (недостаточно для выстрела).
   * *Подсказка:* `«Открой рот увереннее — сейчас амплитуда слишком мала для выстрела»`.
3. **Неполный силовой щит:**
   * *Срабатывание:* Раскрыто 3-4 пальца вместо 5.
   * *Подсказка:* `«Раскрой все 5 пальцев шире и поверни ладонь к камере»`.
4. **Позиционирование в кадре:**
   * *Срабатывание:* Кисть находится у края кадра (< 10% от границы).
   * *Подсказка:* `«Смести руку ближе к центру для стабильного трекинга»`.
5. **Резкие рывки:**
   * *Срабатывание:* Скорость движения курсора > 4.2 ед/сек на протяжении нескольких кадров.
   * *Подсказка:* `«Двигай рукой плавнее для стабильного прицеливания»`.

## 🚀 3. Запуск и установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/aibarryss/pewpew_aim.git
cd pewpew_aim

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
```

Откройте в браузере `http://localhost:3000` и разрешите доступ к веб-камере.

## 🛠️ Стек технологий

* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS
* **Computer Vision:** MediaPipe Hands (21 Landmark tracking на 60 FPS прямо на GPU)
* **Audio:** Web Audio API Procedural Synthesizer (без внешних тяжелых MP3 файлов)
* **Visuals & Effects:** HTML5 High-Performance 2D Canvas Engine, Canvas Confetti
